MiniSEED correction semantics are maintained in:

    ../docs/clock-timing-matrix.md

ClockOffset = instrument time - GPS time = -gps.clockdrift.
TimeCorrectionApplied is already added to the Recording start.
With the MiniSEED applied bit unset, positive fixed-header correction moves
the stored start later. With the bit set, readers do not add it again.
SEED Blockette 57 uses a separate filter-correction convention.

Read-only record inspection:

    python -m obspy.io.mseed.scripts.recordanalyzer -a <mseed_filename>

Use conda pymaid3.10 for the automaid environment. Never toggle applied bits
or edit headers on canonical products merely to inspect timing.
